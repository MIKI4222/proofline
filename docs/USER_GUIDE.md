# User guide

1. Explore public milestones without a wallet. Search and filters apply to loaded records; Load more to broaden them. Open a milestone for criteria, status, attempts, and available history.
2. Connect an injected wallet and select Studio Dev (61997) for personal views and writes. Create uses five steps: project, criteria, deadline/reference, optional executor, review. A blank executor can be claimed by the first valid submitter.
3. A permitted executor can submit public evidence from the milestone; if allowed, they may revise. The creator or executor can request evaluation when the contract state allows it.
4. Review the fee quote, confirm, sign, and wait for the decision and finalization. If tracking is interrupted, resume the stored transaction rather than sending a duplicate. Refresh contract data afterward.
5. The verification report presents the latest available assessment per attempt. Confidence is informational only. Read How it works for important limitations.

Wallet signing, fee estimation and complete live write workflows remain unverified; this is a preview, not a production guarantee.
